How this works

Every icon, tool button, tab, section box and the viewport is a real block from your UV Studio spec. Drag anywhere to move. Drag the bottom-right corner to resize. Double-click a label to rename it in place. Switch tabs on the left to lay out each one separately — your changes autosave in this browser. When you're happy, hit Export layout and send me the JSON — I'll turn it into real panel code.

Select: Shift-click adds to the selection. Drag on empty canvas (or on an unselected frame) to box-select. Ctrl/⌘-click picks one item inside a group. Right-click for more.
Lock the background frames (Layers → Lock frames) so clicks go through them.
